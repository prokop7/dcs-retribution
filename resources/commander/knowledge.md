# Commander knowledge

General lessons about the game and the planning tools that hold in every
campaign. Commanders add to the player's copy with record_lesson.

- F-16CM: the 4x HARM loadout carries no fuel tanks. Use it only for targets
  within about 70 nm; beyond that use the 2x HARM + 2 tanks loadout.
- Navigation points can't be inserted after a strike flight's target
  waypoints; edit_flight_waypoints lists the indices where inserts are valid.
